For now (version 1.3.0) there is only 1 command added to Obsidian.
De-activate this in [[plugin-settings#Plugin|Plugin Settings > Plugin]] if you already have too much commands :)

# 1. Command: "Add all Gantt properties to current file"

As the name implies, this command adds all known event frontmatter properties to the current note.
Only works with normal Markdown files.

> [!tip] If you renamed the frontmatter properties, they will get added exactly as you wished.
